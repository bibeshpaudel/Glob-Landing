100% Offline & Private

Zero telemetry. Zero cloud. Zero indexing bloat.

Your filesystem and source code are strictly yours. Glob Explorer operates completely offline without network capabilities or persistent daemons.

No network permission

The Windows AppX package manifest does not declare the internetClient capability. It is cryptographically prohibited by the OS from making inbound or outbound network calls.

No background service

0% CPU and 0 MB RAM when closed. No persistent indexing services running 24/7, chewing battery or degrading SSD endurance. Search runs strictly on demand.

Clean local JSON storage

Settings, pinned tabs, and window positions are saved exclusively as human-readable JSON files in %LOCALAPPDATA%. Zero clutter or keys added to the Windows Registry.
