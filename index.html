100% Offline & Private

Zero Telemetry. Zero Cloud. Zero Indexing Bloat.

Your filesystem and source code are strictly yours. Glob Explorer is built to operate without network permissions or background daemon drain.

No Network Permission

Glob Explorer does not even declare the internetClient capability in its Windows AppX manifest. It is physically impossible for data to leak off your computer.

Zero Background Service

Consumes 0% CPU and 0 MB RAM when closed. Never runs a background indexing daemon that thrashes SSD read cycles or burns laptop battery.

Local JSON Storage

Preferences (settings.json), pinned tabs (pinned.json), and rotating local diagnostics live strictly in your %LOCALAPPDATA% directory.
